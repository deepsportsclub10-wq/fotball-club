# DEEP Sports Club - Online Administration System

Welcome to the **DEEP Sports Club** web platform. This repository contains the complete front-end architecture for a modern football club website, featuring a dedicated administrative dashboard and public-facing club pages.

## 📌 Project Overview
This project is built to optimize daily sports club operations. It provides a centralized digital interface for club managers to handle administrative tasks while maintaining an engaging public website for fans and players.

## ✨ Key Features
* **Admin Dashboard (`admin.html`):** A secure panel for administrators to manage club operations.
* **Roster Management:** Tools to track, add, and edit player profiles and team rosters.
* **Match Scheduler:** Interface to coordinate match fixtures, training sessions, and events.
* **Performance Analytics:** Dashboards to track team and player statistics.
* **Public Pages (`pages/`):** Responsive web pages designed for club news, schedules, and fan engagement.
* **Media Assets (`images/`):** Optimized graphic assets and photography for the football club theme.

## 📂 Project Structure
```text
├── admin.html      # Main administration dashboard interface
├── admin.css       # Styling for the admin panel
├── admin.js        # Dynamic functionality for club management
├── pages/          # Directory containing public website pages
└── images/         # Directory containing logos, player photos, and graphics
```

## 🚀 How to Run the Project
1. **Clone the repository** or download the ZIP file.
2. Open the root folder on your computer.
3. Double-click `admin.html` to open the administrative dashboard in any modern web browser.
4. Navigate through the `pages/` directory to view the public club website.

## 🛠️ Technologies Used
* HTML5
* CSS3 (Responsive Grid & Flexbox)
